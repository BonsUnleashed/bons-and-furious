# Bons and Furious for Minecraft 1.21.1 / NeoForge

Targeted optimizations and fixes for Minecraft and optional mods, with one switch per control.

Requires Java 21 and NeoForge 21.1.252 or newer. The port carries 205 controls from Bons and Furious 1.0.38. The Forge 1.20.1 release remains on [main](https://github.com/BonsUnleashed/bons-and-furious/tree/main).

[Download 1.0.38+mc1.21.1](https://github.com/BonsUnleashed/bons-and-furious/releases/tag/v1.0.38%2Bmc1.21.1) · [Installation and compatibility](https://github.com/BonsUnleashed/bons-and-furious/wiki/Minecraft-1.21.1-NeoForge) · [Source and build instructions](source/README.md) · [Control coverage](source/PORT-COVERAGE.md) · [Test results](source/QUALIFICATION.md)

Dedicated-server, Iris with shaders, Embeddium, Accelerated Rendering, ServerCore, Generator Accelerator, Bye Pregen and Sable with Storage Drawers checks passed. Terrain matched with the controls enabled and disabled in the base game, with TerraBlender and Oh The Biomes We've Gone, with Generator Accelerator and with Bye Pregen. This port has no published speed benchmark; the Forge measurements apply to 1.20.1 only.
